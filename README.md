# Agent World Map

A technical 3D holographic globe locator of every agent in the official MCP Registry (registry.modelcontextprotocol.io).

## Live

**https://map.utalabs.tech** (after DNS CNAME configuration)
**https://eddyflores100-lang.github.io/agent-world-map** (GitHub Pages default)

## How it works

### Agent positioning

Each agent is positioned on the globe using **namespace TLD analysis**:

| Namespace prefix | Region | Example |
|---|---|---|
| `ae.*` | UAE (24°N, 54°E) | `ae.beachclubs/mcp` |
| `cn.*` | China (35°N, 105°E) | `cn.example/server` |
| `io.github.*` | Distributed globally (hash-based) | `io.github.eddyflores100-lang/uta-shield` |
| `com.*` | United States (39°N, 98°W) | `com.example/api` |
| `eu.*` | Europe (50°N, 10°E) | `eu.example/service` |

Within each region, agents are distributed using a **deterministic hash** of the agent name — this ensures stable positions across page reloads and creates visible clusters.

### Agent classification

Agents are classified into 8 kinds based on name + description pattern matching:

| Kind | Color | Detection pattern |
|---|---|---|
| 🔴 Firewall | `#ff6b35` | `firewall\|shield\|guard\|protect\|waf` |
| 🔵 Payment | `#00d4ff` | `x402\|payment\|wallet\|usdc\|billing` |
| 🟣 Compute | `#a78bfa` | `compute\|gpu\|inference\|render\|train` |
| 🟡 Directory | `#fbbf24` | `registry\|directory\|catalog\|index` |
| 🟢 Publisher | `#22c55e` | (default — MCP servers that publish tools) |
| 🩷 Bridge | `#ec4899` | `bridge\|gateway\|proxy\|a2a\|connector` |
| 🔴 Observer | `#f43f5e` | `threat\|audit\|monitor\|ioc\|phish\|malware` |
| ⚪ Consumer | `#94a3b8` | (passive — not yet detected) |

### Protocol detection

- **x402**: agents with `x402Support: true` in their `_meta.publisher-provided` field → glow brighter + cyan halo
- **Barter**: agents with `barterAccepted: true` → glow brightest + orange halo
- **Agent Card**: agents with an `agentCard` URL → purple tag in panel

### Data source

`data/agents.json` is generated by scanning the entire MCP Registry via `GET /v0/servers?limit=100` with cursor pagination. Each page returns 100 server versions; we group by name and aggregate across all versions.

Current scan: **7,547 unique agents** across **20,000+ versions** from **200 pages**.

## Deployment

### GitHub Pages (automatic)

The repo has GitHub Pages enabled with CNAME `map.utalabs.tech`. To activate:

1. In Cloudflare DNS for `utalabs.tech`, add:
   ```
   Type:  CNAME
   Name:  map
   Target: eddyflores100-lang.github.io
   Proxied: Yes
   ```

2. Wait 5 minutes for DNS propagation.

3. Visit `https://map.utalabs.tech`

### Hostinger (manual upload)

1. Download the ZIP from the [releases page](../../releases) or clone the repo.

2. Upload to Hostinger via cPanel File Manager or FTP:
   - Upload ALL files to `public_html/map/` (or a subdomain root)
   - Files needed:
     ```
     index.html
     css/style.css
     js/three.js
     js/globe.js
     data/agents.json
     .htaccess (optional — for compression)
     ```

3. If using a subdomain `map.utalabs.tech`:
   - In hPanel → Subdomains, create `map.utalabs.tech`
   - Set document root to `public_html/map`
   - Upload all files there

4. If `utalabs.tech` is on Cloudflare (which it is):
   - Add CNAME: `map` → `eddyflores100-lang.github.io` (for GitHub Pages)
   - OR add A record pointing to your Hostinger IP (for Hostinger hosting)

## Tech stack

- **Three.js r149** (UMD build, loaded locally — no CDN dependency)
- **Pure static HTML/CSS/JS** — no build step, no framework, no dependencies
- **3MB data file** (agents.json) loaded client-side via `fetch()`
- **WebGL rendering** with `THREE.Points` for 7,000+ agents at 60fps
