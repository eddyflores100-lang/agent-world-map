# Agent World Map

A 3D holographic globe of every agent in the official MCP Registry (registry.modelcontextprotocol.io).

Each agent is rendered as a point on the Earth sphere. Geographic origin is inferred from the namespace TLD (e.g., `ae.*` → UAE, `cn.*` → China, `io.github.*` → distributed globally by hashing the username).

## Live at

**https://map.utalabs.tech**

## Features

- 🌐 3D holographic Earth with all MCP agents as glowing points
- 🛡️ Color-coded by agent kind (firewall, payment, compute, directory, publisher, bridge, observer)
- 🔍 Click any point → side panel with full agent info (name, version, wallet, repo, region)
- 🎯 Filter by kind, x402, or barter capability
- 🔄 Auto-rotate + drag-to-spin + scroll-to-zoom
- ⚡ Live data from registry.modelcontextprotocol.io (refreshed every page load via `all_agents.json`)

## Data source

The `all_agents.json` file is generated by `fetch_all_agents.py` which paginates through the entire MCP Registry (~17,000+ unique agents across ~47,500 versions as of Oct 2026).

## Tech
